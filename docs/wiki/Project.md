Where the plugin is developed, how decisions are recorded, and how to report a problem.

- **Source and development notes:** the [repository](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc). The [README](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc#readme) covers the test suites, the style build test and continuous integration.
- **Contributing:** [CONTRIBUTING.md](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc/blob/master/CONTRIBUTING.md) sets out the path from issue to merge and what a pull request's test plan covers.
- **Decision log:** [docs/DECISIONS.md](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc/blob/master/docs/DECISIONS.md) records why the plugin works the way it does, with the alternatives that were rejected. Check it before proposing a change to settled behavior.
- **Report a problem:** open an [issue](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc/issues). Name the screen or command, what you did, what you saw (the exact message, if any) and what you expected.
- **Releases:** [Releases](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc/releases) lists each version and what changed in it.

## These pages

The wiki is published from [`docs/wiki/`](https://github.com/UAMS-Web/UAMSWP-Find-a-Doc/tree/master/docs/wiki) by the `Publish wiki` workflow, on each published release and when it is run by hand. Each publish replaces the whole wiki with that folder, so change a page through a pull request, never in the wiki's own editor.
